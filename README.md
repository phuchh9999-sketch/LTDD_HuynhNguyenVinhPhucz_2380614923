	- Nếu người dùng là nhân viêsn: vào Dashboard của nhân viên tương ứng
	- Nếu người dùng là khách hàng hoặc...: Vào trang tương ứng
4. Các chức năng CRUD (5.5đ)
5. Chọn 3 trong 6 chức năng đã làm thuyết trình (3,5)
	a. Đăng nhập bằng khuôn mặt
	b. Chia sẻ vị trí
	d. Đo tiếng ồn hoặc chuyển động hoặc áp xuất
	e. Nhận diện vân tay/NFC/QR/Barcode
